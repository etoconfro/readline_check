# Readline в браузере: как выложить бесплатно

Это веб-версия Readline. Она работает в Safari на iPhone и ставится на экран «Домой» как обычное приложение. Аккаунт разработчика Apple не нужен. Хостинг бесплатный: GitHub Pages.

## Что внутри папки

- `index.html`, `style.css`, `app.js` — само приложение
- `manifest.webmanifest`, `sw.js` — чтобы ставилось на экран «Домой» и работало без интернета
- `icons/` — иконка (та же, что у приложения)

## Шаг 1. Аккаунт GitHub (бесплатно)

1. Откройте на Mac сайт **github.com** и нажмите **Sign up**.
2. Введите почту, пароль и имя пользователя (например `arslanaliev`). Имя войдёт в адрес приложения.

## Шаг 2. Хранилище для файлов

1. Справа вверху нажмите **+** → **New repository**.
2. Repository name: `readline`.
3. Оставьте **Public** (бесплатный хостинг работает только для публичных; в интернет попадает только код, ваши сценарии и видео остаются на телефоне).
4. Нажмите **Create repository**.

## Шаг 3. Загрузить файлы

1. На странице нового хранилища нажмите ссылку **uploading an existing file**.
2. Откройте папку `Readline-PWA` в Finder, выделите **всё её содержимое** (Cmd+A) и перетащите в окно браузера. Папку `icons` тоже, целиком.
3. Внизу нажмите зелёную кнопку **Commit changes**.

## Шаг 4. Включить сайт

1. В хранилище откройте **Settings** → слева **Pages**.
2. В «Build and deployment» → Source: **Deploy from a branch**.
3. Branch: **main**, папка **/ (root)** → **Save**.
4. Подождите 1–2 минуты и обновите страницу. Наверху появится адрес вида
   `https://ВАШЕ-ИМЯ.github.io/readline/`

## Шаг 5. Поставить на iPhone

1. Откройте этот адрес в **Safari** на iPhone.
2. Нажмите **Поделиться** (квадрат со стрелкой) → **На экран «Домой»** → **Добавить**.
3. Запускайте Readline с иконки. Он откроется на весь экран, без адресной строки.
4. При первой записи разрешите камеру и микрофон.

## Как обновлять

Когда я пришлю новую версию: в хранилище снова **Add file → Upload files**, перетащите файлы, **Commit changes**. Через минуту на телефоне закройте и откройте Readline (иногда нужно два раза).

## Важно про данные

- Сценарии и видео хранятся только внутри Readline на этом телефоне.
- **Если удалить иконку Readline с экрана «Домой», всё удалится.** Время от времени жмите «Настройки → Сохранить копию сценариев».
- Готовое видео сохраняйте в «Фото»: открыть дубль → **Сохранить** → **Сохранить видео**.
